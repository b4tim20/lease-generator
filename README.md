# Residential lease generator

A self-contained HTML tool that produces a residential lease agreement as a printable document.
No server, no dependencies, no network calls — open the file and fill in the form.

| File | Produces |
|---|---|
| `residential_lease_engine.html` | residential lease agreement, 66 fields (parties, premises, rent, grace period, late fee, deposit, …) |

It renders a complete document for print/PDF from the entered values; nothing is transmitted anywhere.

**Not legal advice.** This is a drafting aid; have a lawyer review any agreement before use.
