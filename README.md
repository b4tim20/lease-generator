# Lease generator

Two self-contained HTML tools that produce residential and commercial lease agreements as printable
documents. No server, no dependencies, no network calls — open the file and fill in the form.

| File | Produces |
|---|---|
| `residential_lease_engine.html` | residential lease agreement, 66 fields (parties, premises, rent, grace period, late fee, deposit, …) |
| `commercial_lease_engine.html` | commercial lease agreement |

Both render a complete document for print/PDF from the entered values; nothing is transmitted anywhere.

**Not legal advice.** These are drafting aids; have a lawyer review any agreement before use.
